# Image Viewer

Nova's Image Viewer opens a website image in a dedicated viewer so you can inspect details without zooming the entire webpage.

## Open and inspect an image

Right-click an image on a webpage and choose **Magnify image**. The context menu also offers **Open image in new tab** when you want the original image in an ordinary browser tab.

In the viewer you can:

* Zoom in and out, return to original size, or fit the image to the available area.
* Pan a magnified image and use the navigator preview to orient yourself.
* Move or resize the navigator and reset its position.
* Save the image through the viewer's save action.
* Close the viewer and return to the source page.

The viewer is for the selected image. It does not perform OCR, describe image content for the agent, edit pixels or extract PDF pages. Whether an image opens successfully depends on its source and the applicable browser/session restrictions.
