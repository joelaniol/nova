# Research

Research tools help agents gather evidence and distinguish supported claims from unknowns. They do not automatically certify an answer: the agent must select relevant sources, inspect their contents and report what those sources establish.

| Topic | What it covers |
| :--- | :--- |
| [Evidence Verification Mode (EVM) & Visual Evidence](evidence-verification-mode-evm/README.md) | Claim tests, source requirements, unknowns, screenshots and visual comparisons. |

## Related research capabilities

* [Autonomous Crawler & Surface Explorer](../crawler-and-discovery/README.md) — Discovering pages and inspecting website surfaces.
* [PDF Reading & Export](../media-intelligence/pdf/README.md) — Reading document text and preserving webpages as PDFs.
* [Learning](../learning/README.md) — Persistent knowledge and task progress.
* [Session Recording](../session-recording/README.md) — Captured browser events for investigating a run.

Discovery locates material; extracting text makes it available for examination; EVM describes how evidence supports a factual conclusion. A discovered URL or successfully read document is not itself a verified claim.
