## Do I need to enter it?

Usually not. The setup and Nova's sign-in window come with this license already filled in, so a fresh installation only needs a click on **Next** or **Sign in**.

Enter it by hand only if a field is empty, for example:

* an older setup that still asks for the key,
* you cleared the fields during setup and want to activate now,
* Nova shows its sign-in window (**Sign in with your license**) after you signed out.

If you have a license key of your own, overwrite the prefilled fields with it.

## Where it is entered

* **During setup:** on the page **Activate Nova now (optional)**.
* **In the app:** in the sign-in window that Nova shows when it is not activated.
