# Research

Research methods, empirical studies and Nova's evidence-verification tools.

## Evidence & Verification

Research tools help agents gather evidence and distinguish supported claims from unknowns. They do not automatically certify an answer: the agent must select relevant sources, inspect their contents and report what those sources establish.
