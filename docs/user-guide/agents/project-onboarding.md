# Project Onboarding

Project onboarding is optional. It gives your agent Nova reference notes in your current project. Follow [Advanced onboarding](../../getting-started/advanced-onboarding.md) for the prompt, the files it writes and how to check the result.

Onboarding is separate from [connecting your AI program](connecting-an-agent.md) and from [learning a website workflow](../../getting-started/learn-mode.md). It does not configure your AI program's permission allowlist.
