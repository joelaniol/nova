# AI & Agents Settings

Open **Menu → Settings → AI & agents → Access & rules** to review browser access and the autonomy level. Review separate confirmation policies under **AI & agents → Confirmations & audit** when available.

See [Permissions](../identity-and-security/permissions.md), [Terminal](../tools/terminal.md) and [Taking over and emergency stop](../agents/taking-over-and-emergency-stop.md) for the existing guides. To add a connection, use [Connecting an agent](../agents/connecting-an-agent.md).
