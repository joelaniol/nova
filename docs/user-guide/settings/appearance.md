# Appearance

Open **Menu → Settings → Appearance & performance → AI visualization** to review the assist cursor, reduced motion and optional step card. You can also toggle the visualization through **Menu → View → AI visualization**.

See [Watching agent work](../agents/watching-agent-work.md) for the existing guide. A complete guide to the remaining appearance settings is being prepared.
