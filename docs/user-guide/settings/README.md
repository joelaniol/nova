# Settings

Open **Menu → Settings**. Choose a section below, or use **Set up** to [connect an AI program](../agents/connecting-an-agent.md).

| Section | What it covers |
|---|---|
| [General](general.md) | Language, search engine, startup & tray, downloads, auto-open, and diagnostics |
| [Appearance](appearance.md) | Hardware acceleration, sleeping tabs, anti-throttling, cache, and AI visualization |
| [Site permissions](site-permissions.md) | Hardware defaults, remembered decisions, media privacy, notifications, and agent grants |
| [AI & agents](ai-and-agents.md) | Browser control, autonomy levels, advanced limits, confirmations, and audit log |

## Find the right setting

| You want to change … | Start here |
|---|---|
| Language, search engine, or startup tray behavior | **General**; see [General settings](general.md) |
| Download folder or automatic opening of file types | **General**; see [Downloads](../browser/downloads.md) |
| Separate accounts, sandbox names or start pages | **Sandboxes**; see [Sandboxes and profiles](../identity-and-security/sandboxes-and-profiles.md) |
| Website access to devices or location | **Site permissions**; see [Permissions](../identity-and-security/permissions.md) |
| Notification defaults, Do Not Disturb, or desktop alerts | **Site permissions**; see [Desktop notifications](../browser/notifications.md) |
| Agent access, autonomy or terminal behavior | **AI & agents**; see [Permissions](../identity-and-security/permissions.md) and [Terminal dock](../tools/terminal.md) |
| Hardware acceleration, sleeping tabs, or the assist cursor | **Appearance**; see [Appearance & performance](appearance.md) |

For a temporary interruption, use **Menu → Emergency stop**. To disable browser control more generally, switch off **Allow agents to control the browser** in settings. See [Staying in control](../agents/taking-over-and-emergency-stop.md#3-staying-in-control) for the difference.
