# Site Permissions

Open **Menu → Settings → Site permissions** to review defaults, remembered website choices, media activity and site-data grants. To inspect the current website, use the **site info** button beside the address bar.

See [Website and agent permissions](../identity-and-security/permissions.md) for what the decisions mean and how to change them.
