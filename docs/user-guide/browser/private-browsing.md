# Private Browsing

Open **Menu → New private tab** or press **Ctrl+Shift+N**. Private tabs use a temporary session separate from normal tabs. Tabs in the same private session can share a login.

The session ends when its last tab closes and is not restored after a restart. Downloaded files remain on disk. Private browsing does not hide your activity from websites or your network.

For persistent separate logins, use [Sandboxes and profiles](../identity-and-security/sandboxes-and-profiles.md). For access requests, see [Permissions](../identity-and-security/permissions.md).
