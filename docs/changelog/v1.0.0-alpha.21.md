# EN

## New features and improvements

### User interface, toolbar and tabs

- An update button appears in the toolbar as soon as a new version is available or downloading, opening an update panel that links directly to "What's new in version X" in a Nova tab and checks daily in the background
- Tabs survive closing Nova from external scripts or the installer via `--quit`, offering to restore open tabs on the next startup without falsely claiming the browser crashed
- A tab opened in the background no longer shows its page at half the window's width when it comes to the front: Nova now makes the page take the window's real size
- The size indicator in the toolbar says "Page does not fit the window" instead of claiming the page is smaller, which was wrong when it was larger. It also appears after two seconds when Nova cannot remove a background size right away, and the page takes the window's size as soon as a long agent action in that tab ends
- A tab an agent opened in the background no longer stays half grey after it comes to the front. Nova removes the background size it gave the tab before the agent acts in it; if that ever fails, the size indicator in the toolbar shows it right away and resets it with one click
- Background tabs follow the browser window when it is resized, maximized, or moved to another monitor with a different scale factor, matching the display's real pixel density and ensuring clicks inside zoomed or bordered same-origin iframes land reliably on target elements
- The uninstallation dialog now features the unified dark Nova visual design with header and Aurora branding
- Fixed an issue where several German interface dialogs and onboarding strings still displayed the retired product name

### Security and notes

- Stronger protection against prompt injection and knowledge poisoning, explained on the new [Agent Security](../core-features/agent-security/README.md) page. Nova now checks more of what an agent reads for instructions aimed at an AI, entirely on your computer (no text is sent anywhere for the check): besides web pages also PDFs and converted documents, e-mails, fetched resources, crawl results and the results of external tools. The check is harder to trick, raises fewer false alarms on technical documentation, and the answer that raised a suspicion tells the agent to treat the text as untrusted data
- Domain and operator notes clearly identify whether a user or an agent wrote them; an agent cannot store a note under user authorship, and an agent note only becomes binding on future visits once the user explicitly confirms it in Nova
- While a prompt injection is suspected, actions through which data can leave the machine (opening pages, clicking, typing, forms, uploads, mail, remote commands, page scripts) and lasting changes such as notes, memory, scheduled tasks and connectors ask for your confirmation every time, even if they are set to never ask. Scrolling, zoom and tab housekeeping stay unasked. The confirmation dialog then shows a clear "Possible manipulation" warning at the top, and a denied action tells the agent not to retry it
- An agent can change an operator note you wrote only after you confirm it, and the note stays yours
- Purchases always ask: a click that buys, orders, pays, subscribes or hands an order over to payment opens Nova's confirmation dialog every time, even when actions are set to never ask. The dialog shows the total the page lists and the amount the click actually hands on, and warns in red when that amount appears nowhere on the page. Before an agent acts in a shop, Nova reminds it to take item, quantity and price limit from you and to stop when the total differs. Switch: Settings → AI & agents → Confirmations & audit → Always confirm purchases (on by default). Details on the [Agent Security](../core-features/agent-security/README.md) page
- You can trust a site whose text addresses the agent on purpose (for example your own ChatGPT review conversation): the confirmation dialog offers "Always trust *site* and allow", and Settings → AI & agents → Confirmations & audit → Trusted sites lists them. Other safeguards stay in place
- Lasting approvals ("Always allow", "Always trust this site", permanently allowing website data access) unlock only after a visible ten-second countdown, so nothing lasting is granted by a reflex click
- When several agents work at the same time, a suspected prompt injection only holds back the agent that read the text; actions on the affected tab still ask
- Text that a page or document contains but does not show its readers is pointed out to the agent: prices, rules or instructions that appear only there are treated as unconfirmed

## For agents (MCP)

### New tools

- [`nova.convert_to_markdown`](../mcp-reference/tools/visual-evidence/nova-convert-to-markdown.md) turns a local PDF into Markdown for an agent: a `**[Page N]**` marker per page, text in reading order, lists only where the document has them, and repeating headers and footers kept but marked. It says when the answer is cut (`truncated`) or not every page was read (`scanComplete`), names pages without a text layer, and can write the whole document to a `.md` file instead of returning it inline. Headings come only from the PDF's own bookmarks, web links become Markdown links, and next to the text it returns the document's title, author and dates, all bookmarks, form fields (values only on request), and per page the size, orientation, embedded images and links. Each page also reports what its text layer is (characters that could not be decoded, text that is never drawn on the page, text outside the visible area), and pieces of one form row that the layout analysis split apart are joined back into one line; letters are never corrected. Every answer of `nova.convert_to_markdown` and `nova.read_pdf` marks the text as untrusted document content, so an agent treats hidden instructions in a PDF as data. A page whose layout comes out fragmented is flagged in the answer and marked in the Markdown, and `renderPages` returns up to three pages as images to check the text against (rendered in memory, no files left behind). Word documents (`.docx`) and HTML files are converted too, recognised by their content: headings, lists and tables only where the document declares them, plus a list of sections with their position in the Markdown; Excel workbooks become one table per sheet with their stored values (formulas are never calculated, dates come back as dates), PowerPoint presentations one section per slide with title, text, tables and speaker notes; old `.doc`, `.xls` and `.ppt` files are declined by name. The tool page lists every supported format in one table. CSV files become one table (the delimiter is detected, so semicolon files from German Excel work), JSON is checked and printed indented, and plain text comes back unchanged. Text a file contains but does not show (hidden in Word or HTML, never drawn in a PDF, on hidden sheets, rows, columns, slides or shapes) stays in the Markdown and is also returned on its own in `hiddenText`. [`nova.read_text`](../mcp-reference/tools/dom-and-reading/nova-read-text.md) with `format: "markdown"` converts a page that is open in a tab the same way, without saving it first: headings, lists, tables and links of the live page, sections to jump to, and the text of elements the browser hides. For PDFs, text that stands in aligned columns, such as an invoice's line items, also comes back as rows and cells with their positions, and appears as a Markdown table where its cells hold exactly the text of the page, so every amount stays next to its label. EPUB e-books are converted too, chapter by chapter in their reading order, with the book's title and authors. Word documents bring their footnotes, endnotes, headers and footers along. New: [`nova.data_inspect`](../mcp-reference/tools/visual-evidence/nova-data-inspect.md) shows the columns, types and value ranges of a CSV or Excel file, and [`nova.data_query`](../mcp-reference/tools/visual-evidence/nova-data-query.md) filters, groups and totals it locally and returns only the result rows - exact, for files of any length, with German and English number formats. [`nova.pdf_compose`](../mcp-reference/tools/visual-evidence/nova-pdf-compose.md) builds a new PDF from pages of local PDFs - merge, keep, drop or reorder - and [`nova.pdf_split`](../mcp-reference/tools/visual-evidence/nova-pdf-split.md) cuts one into several by page range; the originals stay untouched and nothing is overwritten. [`nova.archive_inspect`](../mcp-reference/tools/visual-evidence/nova-archive-inspect.md) lists the entries of a ZIP, TAR or `.tar.gz` archive without unpacking it, and [`nova.archive_extract`](../mcp-reference/tools/visual-evidence/nova-archive-extract.md) unpacks archives of any size into a new folder in the background, with status and stop, stopping only before the drive runs out of space. It never overwrites a file and never writes entries that would land outside that folder.

### Protocol and capability contracts

- Long-running wait tools (`nova.wait_for_selector`, `nova.wait_for_eval`, `nova.wait_for_modal`, `nova.downloads_wait`) now accept `timeoutMs` up to 1,800,000 ms (30 minutes); when a wait condition is simply not met yet, the call returns `ok=false`, `status='timeout'`, and `waitExpired=true` without `isError`, preventing AI clients from misreporting the wait as an error while ensuring sequence runners stop reliably
- A single page check that misses its budget during heavy CPU activity no longer aborts long waits; `nova.wait_for_selector`, `nova.wait_for_eval` and `nova.wait_for_modal` skip the timed-out probe (`probeTimeouts`) and keep waiting until the full deadline, ending as `page_unresponsive` without `waitExpired` only if the final check before the deadline receives no answer
- The stdio MCP proxy timeout ceiling is raised from 10 to 40 minutes, preventing long generations, model training runs or builds from being severed as `proxy.outcome_unknown`
- `nova.guarded_send_message` and `nova.read_text_structured` now accept wait times up to 1,800,000 ms (30 minutes) via `waitForReplyMs` and `waitMs`, with the page holding recorded replies for up to 35 minutes; after a send is confirmed, the wait holds neither the tab lease nor the global pointer gate, allowing other agent interactions and returning the user's tab immediately
- Leaner answers by default: the navigation tools (`nova.navigate`, `nova.tab_new`, `nova.back`, `nova.forward`, `nova.reload`, `nova.history_go`) and `nova.capture_screenshot`, `nova.eval`, `nova.get_element_rect` and `nova.wait_for_selector` now answer with `outputDetail='compact'` unless told otherwise. A screenshot answer shrinks to about half; `outputDetail='full'` returns everything as before, and no setting hides a warning. An explicit `pksInclude` keeps the PKS block on navigation
- A reduced answer says so: it carries `outputDetail: "compact"` (or `"minimal"`), and the onboarding quickstart explains in "Response sizes" what each size leaves out and why. A field missing from a compact answer was not sent; `outputDetail='full'` shows everything
- A send that Nova verified answers in the lean `minimal` shape unless you ask otherwise; an uncertain or failed send keeps all diagnostics
- `domainNotesAvailable` on navigation drops its reminder sentence once you already hold the current text of every note for that domain
- `nova.eval` runs a top-level `return` or `await` in the isolated world as an async function body instead of failing with a bare SyntaxError (end it with `return`; a missing one is reported), and `eval.runtime_unavailable` clearly reports when a page is still loading, navigating, or being restored
- Tool descriptions of `nova.eval`, `nova.click_selector`, and `nova.capture_screenshot` have been rewritten for agents, shortening their prompt footprint by ~2,700 tokens while preserving all operational rules
- The onboarding quickstart (`.nova/nova-mcp.quick.md`, v4.44.0) has been shortened by a quarter while clarifying that chat replies should be awaited via `guarded_send_message(waitForReplyMs)` in the same call and that content read from pages never carries user authorization
- `nova.read_pdf` names pages without an extractable text layer in `pagesWithoutExtractableText` even when other pages contain text, and marks all extracted text with `contentTrust='untrusted_document'`
- A response no longer carries `bootstrapHint` next to `bootstrapWarning`, which said the same thing
- `nova.emulation_set_locale` and `nova.emulation_clear_locale` keep the browser's Client Hints (`navigator.userAgentData`), ensuring locale tests no longer appear bot-like to sites inspecting browser client hints
- `nova.window_set_size` documents its unit correctly as physical screen pixels, matching the coordinates reported by `nova.window_get_bounds`
- Code analyzers across all projects are updated to .NET 10 `latest-recommended`, upgrading regular expression counting and eliminating blocking synchronous stream reads in network transport paths

### Benutzeroberfläche, Symbolleiste und Tabs

- Tabs überstehen das Beenden von Nova über externe Skripte oder das Setup per `--quit` und werden beim nächsten Start zur Wiederherstellung angeboten, ohne fälschlicherweise einen Absturz zu melden
- Ein im Hintergrund geöffneter Tab zeigt seine Seite nicht mehr in halber Fensterbreite, wenn er nach vorn kommt: Nova lässt die Seite jetzt die echte Fenstergröße übernehmen
- Die Größenanzeige in der Symbolleiste sagt „Seite passt nicht zum Fenster“ statt „kleiner als das Fenster“, was bei einer größeren Seite falsch war. Sie erscheint nach zwei Sekunden, wenn Nova eine Hintergrundgröße nicht sofort entfernen kann, und die Seite übernimmt die Fenstergröße, sobald eine lange Agentenaktion in diesem Tab endet
- Ein Tab, den ein Agent im Hintergrund geöffnet hat, bleibt nicht mehr halb grau, wenn er nach vorn kommt. Nova entfernt die Hintergrundgröße, bevor der Agent darin arbeitet; klappt das einmal nicht, zeigt die Größenanzeige in der Symbolleiste es sofort an und setzt es mit einem Klick zurück
- Hintergrund-Tabs folgen dem Browserfenster beim Vergrößern, Verkleinern, Maximieren oder Verschieben auf einen anderen Monitor mit abweichender Skalierung, passen sich der realen Pixeldichte des Bildschirms an und stellen sicher, dass Klicks in gezoomten oder umrandeten Iframes gleicher Herkunft zuverlässig ihr Ziel treffen
- Der Deinstallationsdialog erscheint nun im einheitlichen dunklen Nova-Design mit Header und Aurora-Branding
- Ein Fehler wurde behoben, bei dem einige deutsche Dialoge und Onboarding-Texte noch den früheren Produktnamen nannten

### Sicherheit und Notizen

- Besserer Schutz gegen Prompt Injection und vergiftetes Wissen, erklärt auf der neuen Seite [Agent Security](../core-features/agent-security/README.md). Nova prüft mehr von dem, was ein Agent liest, auf Anweisungen an eine KI, und zwar vollständig auf deinem Rechner (für die Prüfung wird kein Text irgendwohin gesendet): neben Webseiten jetzt auch PDFs und umgewandelte Dokumente, E-Mails, abgerufene Ressourcen, Crawl-Ergebnisse und Ergebnisse externer Werkzeuge. Die Prüfung lässt sich schwerer austricksen, schlägt bei technischer Dokumentation seltener falsch an, und die Antwort, die einen Verdacht ausgelöst hat, sagt dem Agenten, den Text als nicht vertrauenswürdig zu behandeln
- Domain- und Betreiber-Notizen weisen den Urheber eindeutig als Nutzer oder Agent aus; ein Agent kann eine Notiz nicht als Nutzer speichern, und eine Agenten-Notiz wird für zukünftige Besuche erst bindend, wenn der Nutzer sie in Nova ausdrücklich bestätigt
- Solange ein Verdacht auf Prompt Injection besteht, fragen Aktionen, über die Daten den Rechner verlassen können (Seiten öffnen, Klicken, Tippen, Formulare, Uploads, Mail, Befehle auf Servern, Seitenskripte), und dauerhafte Änderungen wie Notizen, Gedächtnis, geplante Aufgaben und Konnektoren jedes Mal nach deiner Bestätigung, auch wenn sie auf „nie fragen“ stehen. Scrollen, Zoom und Tab-Verwaltung bleiben ohne Rückfrage. Das Bestätigungsfenster zeigt dann oben deutlich „Mögliche Manipulation“, und eine abgelehnte Aktion sagt dem Agenten, sie nicht erneut zu versuchen
- Ein Agent kann einen Arbeitstipp, den du geschrieben hast, nur nach deiner Bestätigung ändern, und der Tipp bleibt deiner
- Käufe fragen immer: Ein Klick, der kauft, bestellt, bezahlt, ein Abo abschließt oder eine Bestellung an die Zahlung übergibt, öffnet jedes Mal Novas Bestätigungsfenster, auch wenn Aktionen auf „nie fragen“ stehen. Das Fenster zeigt die Summe der Seite und den Betrag, den der Klick tatsächlich übergibt, und warnt rot, wenn dieser Betrag nirgends auf der Seite steht. Bevor ein Agent in einem Shop handelt, erinnert Nova ihn daran, Artikel, Menge und Preisgrenze von dir zu übernehmen und bei abweichender Summe anzuhalten. Schalter: Einstellungen → KI & Agenten → Bestätigungen & Protokoll → Käufe immer bestätigen (ab Werk an). Mehr auf der Seite [Agent Security](../core-features/agent-security/README.md)
- Du kannst einer Seite vertrauen, deren Text den Agenten absichtlich anspricht (zum Beispiel dein eigener ChatGPT-Prüfchat): Das Bestätigungsfenster bietet „*Seite* immer vertrauen und erlauben“ an, die Liste steht unter Einstellungen → KI & Agenten → Bestätigungen & Protokoll → Vertrauenswürdige Seiten. Alle anderen Schutzmaßnahmen bleiben bestehen
- Dauerhafte Freigaben („Immer erlauben“, „Seite immer vertrauen“, Zugriff auf Seitendaten immer erlauben) werden erst nach einem sichtbaren Countdown von zehn Sekunden klickbar, damit nichts Dauerhaftes aus Versehen freigegeben wird
- Arbeiten mehrere Agenten gleichzeitig, hält ein Verdacht auf Prompt Injection nur den Agenten auf, der den Text gelesen hat; Aktionen auf dem betroffenen Tab fragen weiter nach
- Text, den eine Seite oder ein Dokument enthält, aber Lesern nicht anzeigt, wird dem Agenten kenntlich gemacht: Preise, Regeln oder Anweisungen, die nur dort stehen, gelten als unbestätigt

## Für Agenten (MCP)

### Neue Werkzeuge

- [`nova.convert_to_markdown`](../mcp-reference/tools/visual-evidence/nova-convert-to-markdown.md) wandelt ein lokales PDF in Markdown für Agenten: je Seite eine Marke `**[Page N]**`, Text in Lesereihenfolge, Listen nur dort, wo das Dokument welche hat, und wiederkehrende Kopf- und Fußzeilen bleiben erhalten, aber markiert. Es sagt, wenn die Antwort gekürzt ist (`truncated`) oder nicht jede Seite gelesen wurde (`scanComplete`), nennt Seiten ohne Textschicht und kann das ganze Dokument als `.md`-Datei schreiben, statt es direkt zurückzugeben. Überschriften kommen nur aus den Lesezeichen des PDFs, Weblinks werden zu Markdown-Links, und neben dem Text liefert es Titel, Autor und Datum des Dokuments, alle Lesezeichen, Formularfelder (Werte nur auf Anfrage) und je Seite Größe, Ausrichtung, eingebettete Bilder und Links. Jede Seite meldet außerdem, wie ihre Textebene beschaffen ist (nicht entschlüsselbare Zeichen, nie gezeichneter Text, Text außerhalb des sichtbaren Bereichs), und Teile einer Formularzeile, die die Layoutanalyse zerrissen hat, werden wieder zu einer Zeile verbunden; Buchstaben werden nie korrigiert. Jede Antwort von `nova.convert_to_markdown` und `nova.read_pdf` kennzeichnet den Text als nicht vertrauenswürdigen Dokumentinhalt, damit ein Agent versteckte Anweisungen in einem PDF als Daten behandelt. Eine Seite, deren Layout zerrissen herauskommt, wird in der Antwort gemeldet und im Markdown markiert, und `renderPages` liefert bis zu drei Seiten als Bild zum Gegenprüfen (nur im Speicher gerendert, es bleiben keine Dateien zurück). Auch Word-Dokumente (`.docx`) und HTML-Dateien werden umgewandelt, erkannt an ihrem Inhalt: Überschriften, Listen und Tabellen nur dort, wo das Dokument sie festlegt, dazu eine Liste der Abschnitte mit ihrer Position im Markdown; Excel-Arbeitsmappen werden zu einer Tabelle je Blatt mit den gespeicherten Werten (Formeln werden nie berechnet, Datumswerte kommen als Datum), PowerPoint-Präsentationen zu einem Abschnitt je Folie mit Titel, Text, Tabellen und Sprechernotizen; alte `.doc`-, `.xls`- und `.ppt`-Dateien werden mit Namen abgelehnt. Die Toolseite führt alle unterstützten Formate in einer Tabelle auf. CSV-Dateien werden zu einer Tabelle (das Trennzeichen wird erkannt, Semikolon-Dateien aus deutschem Excel funktionieren), JSON wird geprüft und eingerückt ausgegeben, reiner Text kommt unverändert zurück. Text, der in der Datei steht, aber nicht angezeigt wird (in Word oder HTML ausgeblendet, im PDF nie gezeichnet, auf ausgeblendeten Blättern, Zeilen, Spalten, Folien oder Formen), bleibt im Markdown und kommt zusätzlich für sich allein in `hiddenText`. [`nova.read_text`](../mcp-reference/tools/dom-and-reading/nova-read-text.md) mit `format: "markdown"` wandelt eine im Tab geöffnete Seite genauso um, ohne sie vorher zu speichern: Überschriften, Listen, Tabellen und Links der lebenden Seite, Abschnitte zum Anspringen und der Text von Elementen, die der Browser ausblendet. Bei PDFs kommt Text, der in Spalten steht, etwa die Positionen einer Rechnung, zusätzlich als Zeilen und Zellen mit ihrer Position zurück und erscheint als Markdown-Tabelle, wo die Zellen genau den Text der Seite enthalten, sodass jeder Betrag bei seiner Bezeichnung bleibt. Auch EPUB-E-Books werden umgewandelt, Kapitel für Kapitel in ihrer Lesereihenfolge, mit Titel und Autoren des Buchs. Word-Dokumente bringen ihre Fußnoten, Endnoten, Kopf- und Fußzeilen mit. Neu: [`nova.data_inspect`](../mcp-reference/tools/visual-evidence/nova-data-inspect.md) zeigt Spalten, Typen und Wertebereiche einer CSV- oder Excel-Datei, und [`nova.data_query`](../mcp-reference/tools/visual-evidence/nova-data-query.md) filtert, gruppiert und summiert sie lokal und gibt nur die Ergebniszeilen zurück - exakt, für Dateien jeder Länge, mit deutschen und englischen Zahlenformaten. [`nova.pdf_compose`](../mcp-reference/tools/visual-evidence/nova-pdf-compose.md) baut aus Seiten lokaler PDFs ein neues PDF - zusammenführen, auswählen, entfernen oder umsortieren - und [`nova.pdf_split`](../mcp-reference/tools/visual-evidence/nova-pdf-split.md) teilt eines nach Seitenbereichen auf; die Originale bleiben unverändert, nichts wird überschrieben. [`nova.archive_inspect`](../mcp-reference/tools/visual-evidence/nova-archive-inspect.md) listet den Inhalt eines ZIP-, TAR- oder `.tar.gz`-Archivs, ohne es zu entpacken, und [`nova.archive_extract`](../mcp-reference/tools/visual-evidence/nova-archive-extract.md) entpackt Archive jeder Größe im Hintergrund in einen neuen Ordner, mit Status und Abbruch, und hält erst an, bevor das Laufwerk voll ist. Es überschreibt nie eine Datei und schreibt nie Einträge, die außerhalb dieses Ordners landen würden.

### Protokoll- und Berechtigungsverträge

- Langlaufende Warte-Werkzeuge (`nova.wait_for_selector`, `nova.wait_for_eval`, `nova.wait_for_modal`, `nova.downloads_wait`) akzeptieren `timeoutMs` jetzt bis zu 1.800.000 ms (30 Minuten); wenn eine Bedingung schlicht noch nicht eingetreten ist, antwortet der Aufruf mit `ok=false`, `status='timeout'` und `waitExpired=true` ohne `isError`, sodass KI-Clients das Warten nicht mehr fälschlich als Fehler einstufen, während Sequenz-Runner verlässlich anhalten
- Eine einzelne Seitenprüfung, die bei hoher CPU-Last ihr Zeitbudget überschreitet, bricht ein langes Warten nicht mehr ab; `nova.wait_for_selector`, `nova.wait_for_eval` und `nova.wait_for_modal` überspringen die abgelaufene Einzelprobe (`probeTimeouts`) und warten bis zur Gesamtfrist weiter; nur wenn auch die allerletzte Prüfung vor Ablauf unbeantwortet bleibt, endet der Aufruf als `page_unresponsive` ohne `waitExpired`
- Die Zeitgrenze des stdio-MCP-Proxys wurde von 10 auf 40 Minuten angehoben, damit langwierige Generierungen, Trainingsläufe oder Builds nicht vorzeitig als `proxy.outcome_unknown` abgerissen werden
- `nova.guarded_send_message` und `nova.read_text_structured` akzeptieren mit `waitForReplyMs` bzw. `waitMs` jetzt Wartezeiten bis zu 1.800.000 ms (30 Minuten), während die Seite empfangene Antworten bis zu 35 Minuten lang puffert; nach dem bestätigten Senden hält das Warten weder die Tab-Sperre noch das globale Zeiger-Gate, sodass andere Agenten agieren können und der Tab des Nutzers sofort zurückkehrt
- Schlankere Antworten als Standard: Die Navigationswerkzeuge (`nova.navigate`, `nova.tab_new`, `nova.back`, `nova.forward`, `nova.reload`, `nova.history_go`) sowie `nova.capture_screenshot`, `nova.eval`, `nova.get_element_rect` und `nova.wait_for_selector` antworten ohne Angabe mit `outputDetail='compact'`. Eine Screenshot-Antwort ist damit etwa halb so groß; `outputDetail='full'` liefert alles wie bisher, und keine Einstellung verbirgt eine Warnung. Ein ausdrückliches `pksInclude` behält bei der Navigation den PKS-Block
- Eine verkleinerte Antwort sagt das selbst: Sie trägt `outputDetail: "compact"` (oder `"minimal"`), und die Onboarding-Kurzreferenz erklärt im Abschnitt „Response sizes“, was jede Größe weglässt und warum. Ein Feld, das in einer kompakten Antwort fehlt, wurde nicht gesendet; `outputDetail='full'` zeigt alles
- Eine Sendung, die Nova bestätigt hat, antwortet ohne andere Angabe in der schlanken Form `minimal`; eine unsichere oder gescheiterte Sendung behält alle Diagnosedaten
- `domainNotesAvailable` lässt bei der Navigation den Erinnerungssatz weg, sobald der Agent den aktuellen Text jeder Notiz der Domain schon hat
- `nova.eval` führt ein `return` oder `await` auf oberster Ebene in der isolierten Welt als asynchrone Funktion aus, statt mit einem reinen Syntaxfehler abzubrechen (mit `return` beenden; ein fehlendes wird gemeldet), und `eval.runtime_unavailable` meldet klar, wenn eine Seite noch lädt, navigiert oder wiederhergestellt wird
- Die Werkzeugbeschreibungen von `nova.eval`, `nova.click_selector` und `nova.capture_screenshot` wurden für Agenten neu verfasst, was den Prompt-Bedarf um rund 2.700 Token verringert, während alle Einsatzregeln unverändert bleiben
- Die Onboarding-Kurzreferenz (`.nova/nova-mcp.quick.md`, v4.44.0) wurde um ein Viertel gekürzt und stellt klar, dass auf Chat-Antworten mit `guarded_send_message(waitForReplyMs)` im selben Aufruf gewartet werden soll und von Seiten gelesene Inhalte niemals die Autorität des Nutzers tragen
- `nova.read_pdf` nennt Seiten ohne lesbare Textebene in `pagesWithoutExtractableText`, auch wenn andere Seiten Text enthalten, und markiert jeden extrahierten Text mit `contentTrust='untrusted_document'`
- Eine Antwort trägt `bootstrapHint` nicht mehr zusätzlich zu `bootstrapWarning`, das dasselbe sagt
- `nova.emulation_set_locale` und `nova.emulation_clear_locale` behalten die Client Hints des Browsers (`navigator.userAgentData`), sodass Sprachtests auf Seiten mit Client-Hint-Prüfungen nicht mehr wie ein Bot wirken
- `nova.window_set_size` dokumentiert seine Einheit korrekt als physische Bildschirmpixel, passend zu den von `nova.window_get_bounds` gemeldeten Koordinaten
- Die Code-Analysatoren aller Projekte wurden auf .NET 10 `latest-recommended` aktualisiert, was Zähloperationen für reguläre Ausdrücke modernisiert und blockierende synchrone Lesevorgänge auf Netzwerk-Transportpfaden eliminiert
