# Changelog — Nova Browser 1.0.0-alpha.17

Nutzersichtbare Änderungen seit `1.0.0-alpha.16` (10.09.2026). Reine interne Test- und Prüfer-Arbeit bleibt bewusst draußen.
User-visible changes since `1.0.0-alpha.16` (2026-09-10). Purely internal test and scanner work is deliberately left out.

---

# EN

## Highlights

- **Targeted context menu hotfix for misspelled words.** Right-clicking a misspelled word in a web page previously presented three blank, active rows without text. Clicking on any of them silently replaced the word with an unknown suggestion. Nova now drops unlabeled menu items, logs their identifier and kind, and cleanly cleans up dangling or consecutive menu separators
- **Official brand slogan.** Adoption of Nova's guiding slogan: *"Built for what's next."*
- **UI scanner against blank interactive elements.** Added `UiBlankRowLabelSelfTest` to statically detect and prevent clickable UI rows whose labels come unvalidated from third-party sources
- **Release verification.** Delivered as `NovaBrowser-Setup-1.0.0-alpha.17.exe` (SHA256: `da1d9b99d2bcd35ee82e9110f97051ea715394a57bc091df9b59b7b8c79d03a9`), fully Authenticode-signed, with all 15,688 test suite checks passing

# DE

## Highlights

- **Gezielter Kontextmenü-Hotfix für Rechtschreibfehler.** Ein Rechtsklick auf ein falsch geschriebenes Wort auf einer Webseite bot bisher drei leere, aber klickbare Zeilen ohne Text an. Ein Klick darauf ersetzte das Wort still durch einen unlesbaren Vorschlag. Zeilen ohne Beschriftung werden nun verworfen, ihre Kennung protokolliert und verwaiste oder doppelte Menü-Trenner sauber nachgeräumt
- **Offizieller Marken-Slogan.** Einführung des Leitslogans für Nova: *„Built for what's next.“*
- **Oberflächen-Prüfer gegen leere Bedienelemente.** Neuer statischer Scanner `UiBlankRowLabelSelfTest`, der klickbare Menüzeilen mit ungeprüften Fremdbeschriftungen im Quellcode aufspürt und künftige Regressionen verhindert
- **Release-Verifikation.** Ausgeliefert als `NovaBrowser-Setup-1.0.0-alpha.17.exe` (SHA256: `da1d9b99d2bcd35ee82e9110f97051ea715394a57bc091df9b59b7b8c79d03a9`), vollständig Authenticode-signiert, mit 15.688/15.688 bestandenen Tests
