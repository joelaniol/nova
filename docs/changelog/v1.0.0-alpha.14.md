# Changelog — Nova Browser 1.0.0-alpha.14

Nutzersichtbare Änderungen seit `1.0.0-alpha.13` (25.07.2026–04.09.2026, 189 Commits im Release-Bereich `d9ed5495..2b924c9a`).
User-visible changes since `1.0.0-alpha.13` (2026-07-25–2026-09-04, 189 commits in release range `d9ed5495..2b924c9a`).

QM-Nummern verweisen auf das interne Findings-Ledger, FR-Nummern auf die Feature-Requests.

# EN

## Highlights

- **Standard Windows user support without administrator rights.** Nova moves all working and profile data to `%LOCALAPPDATA%` and provides explicit diagnostic reporting on failed starts, resolving the fatal first-launch crash under standard accounts (QM-3987, QM-4016)
- **Local offline speech-to-text transcription (FR-031).** Transcribes audio directly on your device without cloud uploads, ships with a bundled baseline model, detects GPU acceleration, and runs in an isolated helper process
- **Capture browser-built and streamed media (FR-027..029).** Captures blob media across frames and shadow roots, MSE/HLS/DASH streaming video, and Web Audio API outputs without requiring direct download links
- **Completely isolated private tabs (FR-026).** Ephemeral browsing sessions with empty cookie jars, no retained history, and explicit session identifiers preventing state leakage between private contexts (QM-3855..3867, QM-3921)
- **Renderer crash protection during PDF generation.** Page PDF export (`nova.save_pdf`) and text extraction (`nova.read_pdf`) run smoothly without triggering accessibility tree renderer crashes (QM-3871..3875)
- **Interactive device emulation controls.** Emulated viewports are rendered with an outline instead of a click-blocking overlay, with independent toolbar resets for metrics, locale, media, touch, and user agents (QM-3845, QM-3846)
- **GPU process failure recovery.** Fallback cushioning prevents continuous browser restart loops on graphics driver crashes, preserving adapter diagnostics across builds (QM-3850..3853)
- **Honest agent communication and click verification.** Eliminated 25 silent failure paths, added real-world action verification to `click_selector` (QM-3903, QM-3904), and measured content completeness bidirectionally (QM-3968..3970)

## New features

### Speech to text, entirely local (FR-031)

- Transcription runs on your own machine; the audio is not uploaded for transcription
- A baseline speech model ships inside the installer, so transcription works immediately after installing
- Own settings tab with an explicit model choice; the setup pre-selects the small model and leaves the larger one opt-in
- Additional models can be installed and removed from settings
- A downloaded model is activated only after its checksum matches
- Runs out-of-process, so a failure in the speech engine cannot take the browser down
- Ogg/Opus is decoded, so voice messages from messengers can be read
- Nova detects whether the graphics card can accelerate transcription and reports which backend actually loaded; GPU availability is not treated as proof that it will be faster
- No permanent error state: a failed run can simply be repeated

### Capturing browser-built and streamed media (FR-027, FR-028, FR-029)

Pages increasingly build media in the browser instead of linking to a file. Nova can now get at it:

- **Blob media** — content that only exists inside the page, found across frames and shadow roots
- **Streaming media** — MSE, HLS and DASH streams that never expose a fetchable URL
- **Web Audio** — audio produced by the Web Audio API, not just through MediaSource
- `page_blobs_list` explains why it came back empty instead of just returning nothing

### PDF

- `nova.save_pdf` writes the current page to PDF, and `nova.read_pdf` extracts embedded text from a PDF
- `read_pdf` is part of agent onboarding, so it is found without hunting for it
- `nova.downloads_wait` waits for a download to finish and returns its final path before an agent tries to read it
- Saving a PDF no longer kills the renderer through the tagged-PDF accessibility snapshot (QM-3871..3875)

### Private tabs (FR-026)

- Ephemeral, logged-out browsing context with an empty cookie jar and no browsing history retained after closing
- For checking how a page looks to a first-time visitor
- Available to you and to agents; several isolated private contexts can run side by side (QM-3855, QM-3856..3867)
- `nova.tab_new` reports whether a tab is private and which private session it uses, so a shared session is not mistaken for a fresh one (QM-3921)

### Loops in agent sequences (FR-030)

- A `run_sequence` step can use an earlier step's result (L1)
- A step can run once per list element (L2)
- Live DOM elements are iterated by identity rather than by position, so a shifting list does not derail the run (L3a)
- `forEach.autoScroll` reaches elements in virtualised lists that are not rendered yet (L3b)

### Device emulation you can operate

- A tab stuck in emulation is marked in the toolbar, with a flyout showing exactly which axes differ from the real window — device metrics, locale, media, touch, user agent (QM-3845)
- Each axis can be reset individually, or all at once
- The emulated viewport is outlined instead of covered by an invisible overlay (QM-3846)
- The outline can be switched off in settings

### Graphics-card incidents, with a way out

- When the graphics card fails repeatedly, Nova falls back once without touching your setting, and says so
- The notice offers the matching action — restart, re-enable acceleration, or suppress further notices
- A failed restart is reported as such instead of silently doing nothing
- The notices can be turned off in settings
- The crash log records adapter and driver

### Browsing

- Home button and right-click to return to the sandbox start page
- "Repair display" in the main menu for a tab that stopped presenting
- Address suggestions in the sandbox start-URL field
- Auto-reload: a page can reload itself on an interval, controllable from agents (`nova.auto_reload`)
- Private tabs get their own start page that spells out what is kept and what disappears
- Screen capture is a site permission of its own
- Drag and drop inside pages works again, including dropping files into pages, and has its own setting — with a note that open pages keep their old behaviour until reloaded

- Reachable through `nova.mail_*`, `nova.ftp_*`, `nova.sftp_*` and the `nova.connector_*` tools
- Setup and the permission model are still moving

### Plugin development

- Building your own extensions for Nova
- An unconfirmed stop no longer loses the session, and a discard does not block tab switches (QM-3734)
- The interface is not settled — a plugin written today may need changes tomorrow

# DE

## Highlights

- **Start auf normalen Windows-Benutzerkonten ohne Adminrechte.** Arbeits- und Profildaten liegen sauber in `%LOCALAPPDATA%` und Startfehler werden verständlich diagnostiziert — der fatale Erststart-Absturz unter Standardkonten ist behoben (QM-3987, QM-4016)
- **Vollständig lokale Sprache-zu-Text-Transkription (FR-031).** Umwandlung direkt auf dem Gerät ohne Cloud-Upload, mitgeliefertes Basismodell im Installer, GPU-Erkennung und Prozessisolation gegen Abstürze
- **Erfassung browserinterner und gestreamter Medien (FR-027..029).** Erkennt Blob-Medien über Frames und Shadow Roots hinweg, MSE-/HLS-/DASH-Streams sowie Web-Audio-Ausgaben ohne direkte Download-Links
- **Vollständig isolierte private Tabs (FR-026).** Flüchtige Sitzungen mit leerem Cookie-Speicher, ohne Verlauf und mit eindeutigen Sitzungskennungen zur Vermeidung von Datenlecks (QM-3855..3867, QM-3921)
- **Absturzschutz beim Erstellen von PDFs.** Der PDF-Export (`nova.save_pdf`) und die Textextraktion (`nova.read_pdf`) bringen den Renderer nicht mehr über Barrierefreiheits-Schnappschüsse zum Absturz (QM-3871..3875)
- **Bedienbare Geräte-Emulation.** Emulierte Darstellungsbereiche werden mit Rahmen statt klickblockierenden Overlays gezeichnet und lassen sich achsenweise über die Symbolleiste zurücksetzen (QM-3845, QM-3846)
- **Abfederung von Grafikkarten-Abstürzen.** Verhindert Endlos-Neustartschleifen bei Treiberproblemen und sichert Treiber- und Adapterprotokolle über saubere Builds hinweg (QM-3850..3853)
- **Ehrliche Agenten-Rückmeldungen und Klick-Prüfung.** 25 stille Fehlerquellen beseitigt, echte Wirkungsprüfung für `click_selector` (QM-3903, QM-3904) und Messung der Inhalts-Vollständigkeit in beide Richtungen (QM-3968..3970)

## Neue Funktionen

### Sprache zu Text, vollständig lokal (FR-031)

- Die Transkription läuft auf dem eigenen Rechner; das Audiomaterial wird dafür nicht hochgeladen
- Ein Basismodell liegt im Setup bei, die Umwandlung funktioniert also direkt nach der Installation
- Eigener Einstellungsbereich mit ausdrücklicher Modellwahl; das Setup wählt das kleine Modell vor und lässt das größere freiwillig
- Weitere Modelle lassen sich in den Einstellungen installieren und entfernen
- Ein heruntergeladenes Modell wird erst aktiviert, wenn seine Prüfsumme stimmt
- Läuft in einem eigenen Prozess, ein Fehler in der Spracherkennung kann den Browser also nicht mitreißen
- Ogg/Opus wird dekodiert, damit Sprachnachrichten aus Messengern lesbar werden
- Nova erkennt, ob die Grafikkarte die Umwandlung beschleunigen kann, und meldet das tatsächlich geladene Backend; eine verfügbare GPU gilt nicht automatisch als schneller
- Kein dauerhafter Fehlerzustand: ein gescheiterter Lauf lässt sich einfach wiederholen

### Im Browser erzeugte und gestreamte Medien erfassen (FR-027, FR-028, FR-029)

Seiten bauen Medien zunehmend im Browser zusammen, statt auf eine Datei zu verweisen. Nova kommt jetzt heran:

- **Blob-Medien** — Inhalte, die nur innerhalb der Seite existieren, gefunden über Frames und Shadow Roots hinweg
- **Streaming-Medien** — MSE-, HLS- und DASH-Streams, die nie eine abrufbare URL preisgeben
- **Web Audio** — Ton, der über die Web-Audio-Schnittstelle erzeugt wird, nicht nur über MediaSource
- `page_blobs_list` erklärt, warum es leer zurückkam, statt einfach nichts zu liefern

### PDF

- `nova.save_pdf` schreibt die aktuelle Seite als PDF, `nova.read_pdf` extrahiert eingebetteten Text aus einer PDF-Datei
- `read_pdf` gehört zum Agenten-Onboarding und wird dadurch gefunden, ohne danach zu suchen
- `nova.downloads_wait` wartet auf den Abschluss eines Downloads und liefert den endgültigen Pfad, bevor ein Agent die Datei zu lesen versucht
- Das Speichern eines PDFs reißt den Renderer nicht mehr über den Barrierefreiheits-Schnappschuss mit (QM-3871..3875)

### Private Tabs (FR-026)

- Flüchtiger, ausgeloggter Kontext mit leerem Cookie-Speicher und ohne dauerhaft gespeicherten Browserverlauf
- Um zu sehen, wie eine Seite für einen Erstbesucher aussieht
- Für dich und für Agenten; mehrere unabhängige private Kontexte laufen nebeneinander (QM-3855, QM-3856..3867)
- `nova.tab_new` meldet, ob ein Tab privat ist und welche private Sitzung er verwendet; dadurch gilt eine geteilte Sitzung nicht fälschlich als frisch (QM-3921)

### Schleifen in Agenten-Sequenzen (FR-030)

- Ein `run_sequence`-Schritt kann das Ergebnis eines früheren Schritts verwenden (L1)
- Ein Schritt kann einmal pro Listenelement laufen (L2)
- Über lebende DOM-Elemente wird nach Identität statt nach Position iteriert, eine sich verschiebende Liste bringt den Lauf also nicht aus dem Tritt (L3a)
- `forEach.autoScroll` erreicht Elemente in virtualisierten Listen, die noch gar nicht gezeichnet sind (L3b)

### Geräte-Emulation, die sich bedienen lässt

- Ein Tab, der in der Emulation feststeckt, ist in der Leiste gekennzeichnet; ein Aufklappmenü zeigt genau, welche Achsen vom echten Fenster abweichen — Gerätemaße, Sprache, Medientyp, Touch, Kennung (QM-3845)
- Jede Achse lässt sich einzeln zurücksetzen, oder alle zusammen
- Der emulierte Bereich wird umrandet, statt von einer unsichtbaren Ebene verdeckt zu werden (QM-3846)
- Die Umrandung lässt sich in den Einstellungen abschalten

### Grafikkarten-Vorfälle, mit Ausweg

- Fällt die Grafikkarte wiederholt aus, weicht Nova einmalig aus, ohne deine Einstellung anzufassen — und sagt es
- Der Hinweis bietet die passende Aktion an: neu starten, Beschleunigung wieder einschalten oder weitere Hinweise unterdrücken
- Ein gescheiterter Neustart wird als solcher gemeldet, statt still nichts zu tun
- Die Hinweise lassen sich in den Einstellungen abschalten
- Das Absturzprotokoll hält Grafikkarte und Treiber fest

### Surfen

- Home-Knopf und Rechtsklick zurück zur Startseite der Sandbox
- „Anzeige reparieren" im Hauptmenü für einen Tab, der nichts mehr darstellt
- Adressvorschläge im Start-URL-Feld der Sandboxes
- Automatisches Neuladen: eine Seite kann sich in einem Intervall selbst neu laden, von Agenten steuerbar (`nova.auto_reload`)
- Private Tabs bekommen eine eigene Startseite, die benennt, was bleibt und was verschwindet
- Die Bildschirmaufnahme ist eine eigene Website-Berechtigung
- Ziehen und Ablegen innerhalb von Seiten funktioniert wieder, auch das Ablegen von Dateien in Seiten, und hat einen eigenen Schalter — mit dem Hinweis, dass bereits offene Seiten ihr bisheriges Verhalten behalten, bis man sie neu lädt

- Die Lautsprecherwahl greift
- Für eine Sitzung erteilte Freigaben überleben das Navigieren innerhalb der Seite
- Eine Gerätevorgabe, die ins Leere greift, meldet sich selbst, statt still zu scheitern
- Eine fallengelassene Gerätevorgabe wird aufgeräumt

**Wahrnehmung und Interaktion**
- `perceive` nennt Commit-Point-CTAs vorab (EFF-LI04, EFF-LI05)
- `composer_state` liest den aktuellen Entwurf; `read_text` kann weiterlesen
- `nova.measure_elements` misst Fenster-, Container- und Elementbreite nebeneinander
- `nova.force_pseudo_state` hält CSS-Zustände für visuelle Prüfungen
- Agenten können HTML5-Drag-and-Drop bedienen
- Agenten erfahren, was der Rechtsklick geöffnet hat (QM-3896, QM-3897)
- Novas eigene Dialoge sind für Agenten sichtbar
- Agenten sehen, was die Einstellungsseite zeigt, und erfahren von einem ausstehenden Neustart

**Vertrag und Auffindbarkeit**
- Die eigene Identität muss nicht mehr bei jedem Aufruf wiederholt werden (FR-AGENTID-STICKY, FR-AGENTID-SESSION)
- `outputDetail` entfernt doppelte Felder aus Antworten von Navigation, `type_selector`, `capture_screenshot` und `eval`, ohne Warnungen auszublenden (QM-3920, QM-3921)
- Jedes Fähigkeiten-Bündel ist beim Bootstrap auffindbar
- Additives Schema-Wachstum gilt als verträglich, brechende Änderungen sind abgesichert (QM-3880..3882)
- Zur Laufzeit verfügbare Werkzeuge stehen auch in Discovery und Onboarding (QM-3909, QM-3910, QM-3911)
- Der Bootstrap nennt einen blockierenden Host-Dialog, statt Agenten hineinlaufen zu lassen
- Bootstrap-Hinweis und Bündel-Katalog wiederholen sich nicht mehr (QM-3957, QM-3958)
- Die vollständige Seitennotiz wird nicht mehr bei jedem Aufruf wiederholt (QM-3886)
- Das Schritt-Budget von `run_sequence` richtet sich nach dem Zeitlimit des jeweiligen Schritt-Werkzeugs (QM-3971)
- `tab_claim` übernimmt den eigenen Claim aus einer beendeten Sitzung
- Das Onboarding lehrt `resolve_sandbox(sandboxId)` nicht mehr (QM-3870) und erklärt, was ein abgesichertes Absende-Ergebnis bedeutet (QM-3885)
- Der MCP-Proxy meldet ein laufendes Nova-Update nicht mehr als Installationsfehler (QM-3959)
- Update-Antworten bleiben innerhalb ihrer Größengrenze und behalten eine stabile JSON-Form

**Lernen**
- Lernentscheidungen verwenden Belege aus dem aktuellen Bereich, statt Allzeit-Gesundheit als Beförderungsbeleg zu behandeln (QM-3963)
- Gelerntes Wissen kann wieder alle vier Stufen der Lernschleife durchlaufen
