# Changelog — Nova Browser 1.0.0-alpha.15

Nutzersichtbare Änderungen seit `1.0.0-alpha.14` (04.09.2026–08.09.2026, 133 Commits im Release-Bereich `2b924c9a..1bfb439c`).
User-visible changes since `1.0.0-alpha.14` (2026-09-04–2026-09-08, 133 commits in release range `2b924c9a..1bfb439c`).

QM-Nummern verweisen auf das interne Findings-Ledger, FR-Nummern auf die Feature-Requests.
Der Bereich enthält 64 abgeschlossene Befund-Gruppen; die nutzersichtbaren davon stehen unten,
reine Test-, Build- und Prüfer-Arbeit bleibt bewusst draußen.

The range contains 64 closed finding groups; the user-visible ones are listed below, while
purely internal test, build and scanner work is deliberately left out.

# EN

## Highlights

- **Network inspection and tab-scoped request interception.** Agents can summarize, filter, await, and replay HTTP requests, redact credentials on request, and arm tab-scoped interception rules to block, redirect, or fail requests without freezing the page (FR-NET-INTERCEPT, QM-4237..4245)
- **Self-healing in-app updater and repair checks.** Updates shut down Nova cleanly before setup runs so background services release install files, prevent restart loops with reboot sentinels, and include file-by-file integrity checks in Repair (QM-4269..4297)
- **Terminal runner overhaul with true colors and UTF-8.** Stripped inherited `NO_COLOR` environment blocks so terminal apps show colors, defaulted workspaces to PowerShell 7, and fixed PSReadLine eating box-drawing characters and emojis (QM-4228..4250, QM-4078)
- **Agent traffic routes through configured proxies.** Fixed a critical defect where agent-driven browser traffic silently bypassed configured HTTP/SOCKS proxies for over 3 months (QM-4103..4115)
- **Verification-backed "About Nova" self-test.** The About dialog runs live acceptance tests against the terminal service and measures response latency; status displays "installed" vs "ready" based on actual probing (QM-4254..4268)
- **Restored hardware diagnostic helper.** Fixed executable path and launch resolution so `NovaBrowser.Outrider.exe` starts properly on customer systems to probe hardware (QM-3986, QM-4246)
- **Enforced camera and microphone assignments.** Webpages receive the exact camera and microphone chosen in Nova settings, and dynamic device plugging/unplugging is detected in real time (QM-3976..4006)
- **Truthful agent responses and alias support.** Empty MCP results explain what they do not mean, truncated responses are explicitly tagged (QM-4039), and common agent naming variants are mapped automatically

## New features

### Network inspection and interception for agents (FR-NET-INTERCEPT)

- `nova.network_read` summarises a page's requests instead of returning hundreds of entries, and can filter inside the page
- It can wait for a matching request instead of leaving an agent to poll for it
- Headers come back named, together with the transferred size of a response
- `redact` masks credentials on request, in headers and inside URLs
- The tap also looks into same-origin iframes, and it names what it cannot see instead of implying it saw everything
- `nova.network_intercept_add` creates a tab-scoped rule that can block a request, change it before it goes out or make it fail
- `nova.network_intercept_list` and `nova.network_intercept_clear` show and remove active rules; an emergency stop clears everything at once
- Rules carry a URL scope, a lifetime and a hit limit, so an interception cannot outlive the task it was made for
- The toolbar shows an indicator while any rule is armed, lists the rules and clears them from there
- No request ever waits for an agent decision: a rule decides on its own, which means a forgotten agent cannot freeze a page
- `nova.network_replay` sends a recorded request again, optionally under the tab's own session
- Arming a rule does not ask for confirmation on every call: consent to the tool is given once in settings, the toolbar shows while a rule is armed, and every rule expires by itself
- Clearing a rule releases what it was holding, so nothing stays blocked after the rule is gone

### Tabs an agent can arrange

- `nova.tab_pin` pins and unpins a tab, and `nova.tabs` reports the pinned state
- `nova.tab_move` changes the order of tabs
- `nova.tabs(mine)` separates an agent's own tabs from the ones belonging to the user
- The tab bar scrolls along when a tab is dragged to its edge, so a tab can be dropped outside the visible range

### Terminal settings an agent can read and set

- `nova.terminal_settings_get` and `nova.terminal_settings_set` expose theme, font size and the colour question
- Nova shows a "colours off" chip in the terminal header when programs run without colour, and the tooltip says which of the two reasons applies — Nova's own setting or `NO_COLOR` in your Windows environment
- A terminal session can be restarted from its header
- A session whose working folder no longer exists says so and offers a retry, instead of opening an empty shell

### Reading a page more narrowly

- `nova.read_text_structured` takes a `selector`, so the landmark scan runs over one subtree instead of the whole page; a scope root that is itself a landmark wins over the landmarks inside it, and no match returns an error rather than silently falling back to everything
- `nova.eval(redact)` masks credentials in what a script returns, on request
- `nova.tab_snapshot` also accepts the singular `targetId`, because that is what agents send

### Media file information without external tools

- `nova.media_file_info` reports duration and container of a media file, so a captured recording can be checked without ffprobe

## Experimental — not ready yet

- **Agent knowledge board.** Several agents exchange what they know: one leaves a finding, another picks it up instead of rediscovering it. Still being built out; behaviour and data may change without notice.
- **Connectors.** Mailboxes and file servers (FTP/SFTP) an agent can read from and write to. Usable, but setup and permission model are still moving.
- **Plugin development.** Building your own extensions for Nova. The interface is not settled.

## Setup and start

- The Visual C++ runtime ships with the setup, so speech recognition works on a freshly set-up machine (QM-4052)
- Nova registers with Windows as a browser and appears in "Default apps"; a link opened while Nova is closed arrives in the new window (QM-4152..4172)
- The uninstall dialog speaks the language Nova speaks, and asks once about personal data instead of twice about something similar
- Every installation carries a file list, and **Repair** can check it: it names files that are missing or altered instead of leaving a load error behind (QM-4296)
- An update that Windows can only finish after a restart says exactly that, instead of reporting a failed update (QM-4297)
- Installing an update closes Nova through its normal shutdown, so the terminal service releases the install folder, the open tabs come back afterwards, and the next start is not mistaken for a crash (QM-4269, QM-4270)
- After an update Nova is started again with the flag it needs to wait for the previous instance, so it cannot end up with no window at all (QM-4273)
- A setup that is blocked by a Windows security policy says so, and one that ends immediately is reported as a failed launch rather than as a running install (QM-4274, QM-4286)
- The repair hint points at a folder that exists on a customer machine, and the built setup no longer stumbles over a write-protected checksum
- The setup package no longer carries internal development notes, and the licence handoff is written into the profile of the user who is installing — not into the administrator's, when a different account confirms the prompt (QM-4155, QM-4156)

## Terminal

- Programs in the terminal show colours again: Nova had inherited a `NO_COLOR` setting from whatever started it and passed it on to every shell it opened (QM-4228..4250)
- A workspace without a chosen program starts PowerShell 7 when it is installed, instead of the Windows PowerShell 5.1 from 2016 (QM-4247)
- A hanging session can be ended from its own header, instead of going back to the workspace list to close it there (QM-4248)
- Pasting long text is faster (QM-4250)
- Dragging the window edge no longer reports a new size to the console on every animation frame, so a full-screen terminal program stops redrawing constantly (QM-4236)
- A session that has ended is shown as ended, also when the connection to it had been dropped in between (QM-4233)
- When scrollback has to be dropped because a program wrote too much, the terminal says so instead of losing it silently
- A terminal service with sessions but no browser attached now really leaves after a day, instead of staying for good (QM-4246)
- Box-drawing characters and emoji arrive in an agent's own shell: PSReadLine was dropping them before they reached the console, so table frames came back mangled (QM-4078)
- The terminal no longer flickers while output is arriving

## Settings and interface

- **About Nova** now runs the terminal service's own acceptance checks and then measures the answer time; the result stays visible next to the button and survives switching tabs (QM-4254..4257)
- Where only a file was checked, About says "installed" rather than "ready" — readiness is claimed only where something was actually probed (QM-4261)
- The memory line reports three separate figures under "Memory (main process)" instead of mixing two different quantities (QM-4263)
- The rule set for AI agents is named in everyday words instead of a module name (QM-4262)
- The installed version is written the same way in the update card as in the About header (QM-4265)
- The address bar's inline completion shares one line with what you typed, so the two no longer sit on separate baselines (QM-4193..4195)
- Enter and the suggested completion no longer act on an input you have already changed
- The address bar recognises a host as a term of its own
- Dragging a tab has one mechanism instead of four: no drift back on drop, no jumping title, and the last position is reachable (QM-4200)
- The developer tools have a lifecycle and a keyboard route
- A newly opened tab accepts typing immediately
- The website permissions list no longer builds itself twice when settings open
- The assist overlay no longer covers the thing it is pointing at, and it says when it sees no visible effect
- Pinned tabs keep their boundary while dragging, a sleeping neighbour no longer takes over, and a restored session no longer comes back half-way (QM-4173..4181)
- The agent dot in a tab keeps its size, so an agent becoming active no longer shifts the tab title (QM-4199)

## Permissions and media

- The camera and microphone chosen in settings are the ones a page gets (QM-3976..4006)
- Nova notices when devices are plugged in or removed while it runs, and says so instead of showing a stale list
- A device list that was cut short no longer presents itself as complete
- "Delete all permissions" takes the device assignments with it
- The hardware panel no longer reports an error that did not happen, and the diagnostic camera image is no longer placed in the page's own document
- Speech recognition says where to get the missing runtime instead of failing silently
- Nova only warns about a device deviation you did not ask for: choosing a different device on the page itself no longer produces a warning about it

## Stability, privacy and diagnostics

- Agent traffic really goes through a configured proxy — for three and a half months it silently did not (QM-4103..4115)
- A display that stopped updating after scrolling is no longer triggered by Nova's own recording path (measured: 6 of 6 before, 0 of 7 after)
- A single timeout no longer takes the whole device inventory down with it
- The helper process that ships beside Nova starts again, so hardware probes work on a customer installation
- Repeated GPU-process failures are cushioned once instead of restarting the browser in a loop
- Every page load costs less: work that ran on each navigation without being needed is gone

## For agents (MCP)

### Truthful answers

- An empty result says what it does **not** mean, so "nothing found" is no longer read as "nothing exists"
- No tool stays silent about what it did
- A click whose effect was visible is no longer reported as ineffective
- `nova.eval` returns the value of the last expression, accepts several statements, and says when a script returned nothing
- A screenshot no longer discards the layout size it needs itself, and it no longer takes over the user's tab

### Cost of an answer

- A saving mode omits fields that carry no value
- Response sizes can be measured in the action log (opt-in)
- The names agents actually send are accepted as aliases, so a call from framework memory does not hit a wall

### Fixes for agents

- A read result that exceeds the size limit is truncated with a note, instead of being discarded whole and returned as nothing (QM-4039)
- The network tap no longer holds up the very requests it is there to observe
- An interception rule reports how often it was applied, not how often something matched — a rule that never applied used to look successful (QM-4237..4244)
- A tab that was never shown reports the real window size instead of measuring as a phone without saying so
- Transcription results reach the caller: the handler returned its data in a shape the transport dropped, so an agent got an empty answer for a job that had run (QM-4210..4213)
- Platform knowledge reaches the second agent too, not only the one that wrote it
- Domain notes are asked for their full text instead of being estimated, and a long note no longer arrives in full exactly when it is being closed
- An optional proof screenshot can no longer discard the finished action it was meant to document
- Two provider estimates are no longer attached to every caller on every screenshot
- Two places that cannot carry out a request now say so and name the way around it (QM-3993)
- `nova.network_read` keeps the bodies it is supposed to record
- `nova.tab_move` runs on the right thread and no longer claims a sandbox does not exist when it does
- Speech recognition compares the graphics-driver stamp it collects instead of carrying it along unread, so a driver change really invalidates the earlier verdict (QM-4035, QM-4060..4069)

## Known limitations

- The changes to the update path are only exercised by the in-app updater; installing the setup by hand does not go through them
- Speech recognition runs on the processor; a graphics card is detected and reported but not used for it
- Downgrading to an older version is refused in a silent setup — deliberately, because an older build prunes settings it does not know

## Neue Funktionen

### Netzwerk-Einblick und Abfangen für Agenten (FR-NET-INTERCEPT)

- `nova.network_read` fasst die Anfragen einer Seite zusammen, statt hunderte Einträge zu liefern, und filtert in der Seite
- Es kann auf eine passende Anfrage warten, statt einen Agenten pollen zu lassen
- Header kommen benannt zurück, zusammen mit der übertragenen Größe einer Antwort
- `redact` schwärzt Zugangsdaten auf Ansage — in Headern und in URLs
- Der Mitschnitt sieht auch in same-origin-Iframes und benennt, was er **nicht** sieht, statt Vollständigkeit zu suggerieren
- `nova.network_intercept_add` legt eine Tab-gebundene Regel an, die eine Anfrage blockieren, vor dem Absenden verändern oder scheitern lassen kann
- `nova.network_intercept_list` und `nova.network_intercept_clear` zeigen und entfernen aktive Regeln; ein Notstopp räumt alle auf einmal weg
- Regeln tragen URL-Bereich, Laufzeit und Trefferlimit, damit ein Abfangen die Aufgabe nicht überlebt, für die es gedacht war
- Die Symbolleiste zeigt einen Hinweis, solange eine Regel scharf ist, listet die Regeln auf und räumt sie von dort weg
- Keine Anfrage wartet je auf eine Agenten-Entscheidung: eine Regel entscheidet selbst, ein vergessener Agent kann also keine Seite einfrieren
- `nova.network_replay` schickt eine aufgezeichnete Anfrage erneut, auf Wunsch unter der Sitzung des Tabs
- Eine Regel scharf zu stellen fragt nicht bei jedem Aufruf nach: die Zustimmung zum Werkzeug wird einmal in den Einstellungen gegeben, die Symbolleiste zeigt eine scharfe Regel an, und jede Regel läuft von selbst ab
- Das Aufräumen einer Regel gibt frei, was sie gehalten hat — nach dem Entfernen bleibt nichts blockiert

### Tabs, die ein Agent ordnen kann

- `nova.tab_pin` pinnt einen Tab an und löst ihn wieder, und `nova.tabs` zeigt den Zustand
- `nova.tab_move` ändert die Reihenfolge der Tabs
- `nova.tabs(mine)` trennt die eigenen Tabs eines Agenten von denen des Nutzers
- Die Tab-Leiste scrollt mit, wenn ein Tab an ihren Rand gezogen wird, sodass er auch außerhalb des sichtbaren Bereichs abgelegt werden kann

### Terminal-Einstellungen, die ein Agent lesen und setzen kann

- `nova.terminal_settings_get` und `nova.terminal_settings_set` machen Thema, Schriftgröße und die Farbfrage zugänglich
- Nova zeigt im Terminal-Kopf einen Hinweis „Farben aus", wenn Programme ohne Farbe laufen, und der Tooltip nennt, welcher der beiden Gründe gilt — Novas eigene Einstellung oder `NO_COLOR` in deiner Windows-Umgebung
- Eine Terminal-Sitzung lässt sich aus ihrem Kopf heraus neu starten
- Eine Sitzung, deren Arbeitsordner nicht mehr existiert, sagt das und bietet einen erneuten Versuch an, statt eine leere Shell zu öffnen

### Eine Seite enger lesen

- `nova.read_text_structured` nimmt einen `selector`, sodass der Landmark-Scan über einen Teilbaum statt über die ganze Seite läuft; eine Scope-Wurzel, die selbst ein Landmark ist, gewinnt gegen die Landmarks in ihr, und kein Treffer liefert einen Fehler statt still die ganze Seite
- `nova.eval(redact)` schwärzt auf Ansage Zugangsdaten in dem, was ein Skript zurückgibt
- `nova.tab_snapshot` nimmt auch die singulare Schreibweise `targetId` an, weil Agenten sie so schicken

### Angaben zu einer Mediendatei ohne Fremdwerkzeug

- `nova.media_file_info` nennt Dauer und Behälter einer Mediendatei, sodass sich eine Aufnahme ohne ffprobe prüfen lässt

## Experimentell — noch nicht fertig

- **Agenten-Wissensboard.** Mehrere Agenten tauschen aus, was sie wissen: einer hinterlässt einen Befund, ein anderer greift ihn auf, statt ihn neu herauszufinden. Wird noch ausgebaut; Verhalten und Daten können sich ohne Ankündigung ändern.
- **Konnektoren.** Postfächer und Dateiserver (FTP/SFTP), aus denen ein Agent lesen und in die er schreiben kann. Nutzbar, aber Einrichtung und Berechtigungsmodell sind noch in Bewegung.
- **Plugin-Entwicklung.** Eigene Erweiterungen für Nova bauen. Die Schnittstelle steht noch nicht fest.

## Einrichtung und Start

- Die Visual-C++-Laufzeit liegt dem Setup bei, damit die Spracherkennung auf einem frisch aufgesetzten Rechner funktioniert (QM-4052)
- Nova registriert sich bei Windows als Browser und erscheint unter „Standard-Apps"; ein Link, der bei geschlossenem Nova geöffnet wird, kommt im neuen Fenster an (QM-4152..4172)
- Der Deinstallations-Dialog spricht die Sprache, die Nova spricht, und fragt einmal richtig nach den persönlichen Daten statt zweimal ähnlich
- Jede Installation bringt eine Dateiliste mit, und die **Reparatur** kann sie prüfen: sie benennt fehlende oder veränderte Dateien, statt einen Ladefehler zurückzulassen (QM-4296)
- Ein Update, das Windows erst nach einem Neustart abschließen kann, sagt genau das, statt ein fehlgeschlagenes Update zu melden (QM-4297)
- Beim Einspielen eines Updates schließt sich Nova über den normalen Weg, damit der Terminaldienst den Installationsordner freigibt, die offenen Tabs danach zurückkommen und der nächste Start nicht für einen Absturz gehalten wird (QM-4269, QM-4270)
- Nach einem Update wird Nova mit dem Schalter gestartet, den es braucht, um auf die vorherige Instanz zu warten — sonst kann es passieren, dass am Ende kein Fenster übrig bleibt (QM-4273)
- Ein Setup, das eine Windows-Sicherheitsrichtlinie blockiert, sagt das, und eines, das sofort endet, gilt als gescheiterter Start und nicht als laufende Installation (QM-4274, QM-4286)
- Der Reparaturhinweis zeigt auf einen Ordner, den es auf einem Kundenrechner gibt, und der gebaute Installer stolpert nicht mehr über eine schreibgeschützte Prüfsumme
- Das Setup-Paket trägt keine internen Entwicklungsnotizen mehr mit sich, und die Lizenz-Übergabe landet im Profil des Nutzers, der installiert — nicht im Profil des Administrators, wenn ein anderes Konto die Rückfrage bestätigt (QM-4155, QM-4156)

- Wo nur eine Datei geprüft wurde, sagt „Über Nova" **installiert** statt **bereit** — Einsatzbereitschaft wird nur behauptet, wo tatsächlich geprüft wurde (QM-4261)
- Die Speicherzeile nennt drei getrennte Werte unter „Speicher (Hauptprozess)", statt zwei verschiedene Größen zu vermischen (QM-4263)
- Das Regelwerk für KI-Agenten heißt in Alltagssprache, was es ist, statt einen Modulnamen zu tragen (QM-4262)
- Die installierte Version steht in der Update-Karte genauso da wie im Kopf von „Über Nova" (QM-4265)
- Die Vervollständigung der Adressleiste teilt sich eine Zeile mit dem Getippten, sodass beide nicht mehr auf getrennten Grundlinien sitzen (QM-4193..4195)
- Eingabetaste und Vorschlag entscheiden nicht mehr auf einer Eingabe, die du schon geändert hast
- Die Adressleiste erkennt einen Host als eigenen Begriff
- Das Ziehen eines Tabs hat einen Mechanismus statt vier: kein Rückflug beim Ablegen, kein springender Titel, und der letzte Platz ist erreichbar (QM-4200)

- Ein neu geöffneter Tab nimmt sofort Eingaben an
- Die Liste der Website-Berechtigungen baut sich beim Öffnen der Einstellungen nicht mehr doppelt auf
- Das Assist-Overlay verdeckt nicht mehr, worauf es zeigt, und sagt, wenn es keine sichtbare Wirkung erkennt
- Angepinnte Tabs behalten beim Ziehen ihre Grenze, ein schlafender Nachbar übernimmt nicht mehr, und eine wiederhergestellte Sitzung kommt nicht mehr halb zurück (QM-4173..4181)
- Der Agenten-Punkt im Tab behält seine Größe, sodass ein aktiv werdender Agent den Tab-Titel nicht mehr verschiebt (QM-4199)

## Berechtigungen und Medien

- Die in den Einstellungen gewählte Kamera und das gewählte Mikrofon sind die, die eine Seite bekommt (QM-3976..4006)
- Nova bemerkt, wenn im Betrieb Geräte an- oder abgesteckt werden, und sagt es, statt eine veraltete Liste zu zeigen
- Eine abgeschnittene Geräteliste gibt sich nicht mehr als vollständig aus
- „Alle Berechtigungen löschen" nimmt die Gerätezuordnungen mit
- Das Hardware-Panel meldet keinen Fehler mehr, den es nicht gab, und das Kamerabild der Diagnose liegt nicht mehr im Dokument der Seite
- Die Spracherkennung sagt, woher die fehlende Laufzeit kommt, statt still zu scheitern
- Nova warnt nur noch über eine Geräteabweichung, die du nicht gewollt hast: ein auf der Seite selbst gewähltes anderes Gerät erzeugt keine Warnung mehr

## Stabilität, Datenschutz und Diagnose

- Agenten-Verkehr läuft wirklich über einen eingerichteten Proxy — dreieinhalb Monate lang tat er das still nicht (QM-4103..4115)
- Eine Anzeige, die nach dem Scrollen stehen blieb, wird von Novas eigenem Aufnahmeweg nicht mehr ausgelöst (gemessen: 6 von 6 vorher, 0 von 7 nachher)
- Ein einzelner Timeout reißt die Geräteinventur nicht mehr mit
- Der Helferprozess, der neben Nova ausgeliefert wird, startet wieder — damit funktionieren Hardware-Abfragen auch auf einer Kundeninstallation
- Wiederholte Ausfälle des Grafikprozesses werden einmal abgefedert, statt den Browser in einer Schleife neu zu starten
- Jeder Seitenaufruf kostet weniger: Arbeit, die bei jeder Navigation lief, ohne gebraucht zu werden, ist weg

## Für Agenten (MCP)

### Wahrheitsgemäße Antworten

- Ein leeres Ergebnis sagt, was es **nicht** bedeutet — „nichts gefunden" wird nicht mehr als „es gibt nichts" gelesen
- Kein Werkzeug bleibt stumm darüber, was es getan hat
- Ein Klick, dessen Wirkung sichtbar war, gilt nicht mehr als wirkungslos
- `nova.eval` liefert den Wert des letzten Ausdrucks, nimmt mehrere Anweisungen an und sagt, wenn ein Skript nichts zurückgegeben hat
- Ein Screenshot verwirft nicht mehr die Layout-Größe, die er selbst braucht, und übernimmt nicht mehr den Tab des Nutzers

### Was eine Antwort kostet

- Ein Sparmodus lässt Felder ohne Wert weg
- Antwortgrößen sind im Aktionsprotokoll messbar (opt-in)
- Die Namen, die Agenten wirklich schicken, werden als Aliase angenommen, sodass ein Aufruf aus dem Framework-Gedächtnis nicht gegen eine Wand läuft

### Korrekturen für Agenten

- Ein Leseergebnis über der Größengrenze wird gekürzt und als gekürzt gekennzeichnet, statt ganz verworfen und als „nichts" zurückgegeben zu werden (QM-4039)
- Der Netzwerk-Mitschnitt hält die Anfragen nicht mehr auf, die er beobachten soll
- Eine Abfang-Regel nennt, wie oft sie **angewendet** wurde, nicht wie oft etwas gepasst hat — eine Regel, die nie angewendet wurde, sah vorher erfolgreich aus (QM-4237..4244)
- Ein nie angezeigter Tab nennt die echte Fenstergröße, statt unbemerkt als Telefon zu messen
- Transkriptionsergebnisse erreichen den Aufrufer: der Handler gab seine Daten in einer Form zurück, die der Transportweg verwarf — ein Agent bekam eine leere Antwort auf einen Auftrag, der gelaufen war (QM-4210..4213)
- Die Plattform-Kenntnis erreicht auch den zweiten Agenten, nicht nur den, der sie geschrieben hat
- Der Volltext einer Domain-Notiz wird abgefragt statt geschätzt, und eine lange Notiz kommt nicht mehr ausgerechnet beim Schließen vollständig an
- Ein optionaler Beweis-Screenshot kann die fertige Aktion nicht mehr verwerfen, die er dokumentieren sollte
- Zwei Anbieter-Schätzungen hängen nicht mehr an jedem Aufrufer auf jedem Bild
- Zwei Stellen, die eine Anfrage nicht ausführen können, sagen das jetzt und nennen den Ausweg (QM-3993)
- `nova.network_read` behält die Bodies, die es aufzeichnen soll
- `nova.tab_move` läuft im richtigen Thread und behauptet nicht mehr, eine Sandbox existiere nicht, wenn sie existiert
- Die Spracherkennung vergleicht den Treiberstempel, den sie erhebt, statt ihn ungelesen mitzuführen — ein Treiberwechsel macht das frühere Urteil damit wirklich ungültig (QM-4035, QM-4060..4069)

## Bekannte Grenzen

- Die Änderungen am Update-Weg werden nur vom In-App-Updater durchlaufen; wer das Setup von Hand installiert, geht nicht durch sie hindurch
- Die Spracherkennung läuft auf dem Prozessor; eine Grafikkarte wird erkannt und genannt, aber dafür nicht genutzt
- Ein Downgrade auf eine ältere Fassung wird in einem stillen Setup abgelehnt — bewusst, weil eine ältere Fassung Einstellungen beschneidet, die sie nicht kennt
