# EN

## Highlights

- **The Edge-style favorites panel and smarter tab control.** A dedicated favorites flyout opens from the toolbar or shortcut with fuzzy search, folder hover flyouts and address preview. Right-clicking a tab lets you "Close tabs to the right" to keep work sessions tidy
- **A high-speed SQLite history engine and adaptive address bar.** History is powered by `history.db` with full-text search (searchable by agents via `nova.history_search`), 1-year retention and a 32 MB cache reducing address bar latency to under 10 ms. The omnibox learns what you pick, eliminates ghost-text flicker, reliably dismisses popups, and displays clean addresses like Chrome
- **The permission dialogs are Nova's own now.** Location, clipboard and six more prompts used to be drawn by the browser engine. They now look like Nova, speak like Nova, and what you decide lands in Nova's permission settings where you can look it up and change it
- **Nova asks the security questions itself.** Password prompts of websites (HTTP sign-in, now with your saved logins), invalid certificates, client certificates, and executable files before they are saved: each gets a plain Nova dialog that says what is going on instead of an engine page or silence
- **A guided setup for your AI programs.** Instead of hunting for configuration files, Nova walks you through the connection and writes it for you. Antigravity is found automatically (syncing its separate configs), and connecting in an empty project seeds `CLAUDE.md`, `AGENTS.md` and `GEMINI.md` guidance files
- **Sandboxes grow up.** Up to 100 sandboxes, a scrolling bar with search, and links a sandbox opens in a new tab now stay in that sandbox's session, so you stay signed in. When a site needs a step elsewhere, Nova asks instead of blocking silently
- **A password vault you can manage.** Add, edit and copy logins in settings; the account picker comes back when you need it, works with the keyboard and by right-click, handles sign-ins that ask for the e-mail first, and keeps ports separate
- **Resumable background file transfers & local transcription.** SFTP and FTP transfers run as background jobs with pause, resume, and 8-channel parallel upload speedup in the downloads panel. Local offline audio/video transcription supports MP3, MP4, WebM, and MKV-Opus

## New name and look

- Nova Browser is now called Nova AI Workspace. Inside the app it is simply "Nova" — window title, taskbar, every dialog — and the program file is `NovaAIWorkspace.exe`
- New logo and app icon: a violet arc with a four-pointed star. It appears on the program icon, in the setup wizard, on the licence screen, on the new tab page and in the address bar
- The interface is calmer: toolbar and bookmarks bar share one surface, borders use quiet neutral tones, the active tab merges into the toolbar, inactive tabs have no frame, and hovering a tab no longer lights up three effects at once
- Colours follow their role: violet only marks focus, hover and agent activity, and the toolbar icons are brighter and easier to read
- Panels, menus, dialogs and suggestion lists share one opaque surface, so a bright page no longer shows through them
- Every menu uses Nova's style, including the downloads "…" menu, the navigation bar menu and "Save as" in the transcription window
- The site info panel points at the padlock it belongs to, and tooltips use Nova's colours
- A loading ring around the tab icon shows progress while a page loads, and the "+" new tab button uses clean hover and click states

## New features and improvements

### Favorites panel and tab management

- An Edge-style favorites panel opens from the toolbar or via keyboard shortcut, offering instant fuzzy search and hierarchical tree navigation
- Folders in the favorites panel open beside the row on hover, and the context menu shows the destination address
- Searching favorites uses and refines adaptive suggestion ranking, matching what you pick in the address bar
- Right-clicking a tab offers "Close tabs to the right" to quickly clean up work sessions
- Bookmarks and favorites are stored in a dedicated `favorites.db` database instead of the main settings file
- Fixed an issue where pressing Escape in the favorites panel closed the entire panel instead of clearing the search box first
- Fixed an issue where middle-clicking a favorite triggered on button press rather than release, causing button release to hit elements underneath like the tab bar
- Fixed an issue where multi-level folder sub-panels in favorites prevented the flyout chain from closing and swallowed mouse hover events
- Fixed an issue where deleting a favorite while the panel was open left the deleted item visible until the panel was reopened
- Fixed an issue where searching favorites normalized German "ß" to "s" instead of "ss", so searches like "strasse" never matched "Straße"
- Fixed an issue where favorites sub-panels lacked arrow-key navigation and screen reader announcements for selected rows

### SQLite history and adaptive address bar

- Browsing history runs on a high-performance SQLite engine (`history.db`) with full-text search, visit frecency scoring, automatic 1-year retention and a 32 MB cache that cuts address bar latency to under 10 ms
- Address bar suggestions adapt to you: typing a search text prioritizes the URL you picked for that query in the past
- Web addresses in the address bar are displayed in clean, readable text like Chrome, while copying always supplies the canonical sendable address
- Fixed an issue where navigating wrote to `settings.json` on every page visit, causing unnecessary disk wear and file bloat
- Fixed an issue where encoded query parameters in web addresses were erroneously decoded on navigation, causing 404 errors on sites like AliExpress
- Fixed an issue where pressing Backspace or Delete fought against the inline suggestion (ghost-text), which immediately re-appeared; deleting now suppresses autocompletion until typing forward again
- Pressing Escape in the address bar operates in two steps: the first press restores the original URL and undoes edits while retaining focus in the bar; the second press releases focus back to the webpage
- Repeatedly pressing the Tab key cycles down through suggestion items and exits cleanly, instead of endlessly re-selecting row 0
- Multi-word search queries (e.g. "react docs") match any history or bookmark entry containing all query tokens, rather than requiring a single contiguous substring
- Web search suggestions (Google, Bing) reserve at least two slots and are no longer completely crowded out by history candidates
- Removing a history entry via Shift+Delete works directly on the top suggestion and is strictly guarded to protect saved favorites from accidental deletion
- Cached URL facts cut heap allocations during keystroke pauses by up to 80% (from 1.8–5.6 MB down to 0.35–3.8 MB), discarded input preloads no longer trigger repaints, and titles are no longer arbitrarily truncated at 64 characters
- Fixed an issue where subsequent asynchronous suggestion passes (such as favicon decoration or remote queries) re-evaluated the displayed inline completion (ghost text) as typed text, causing autocomplete to oscillate between suggested and cleared states
- Synchronous text-changing events now strictly own typed input while delayed text-changed echos are treated as non-mutating diagnostics, preventing delayed keystroke echos from triggering unwanted searches on the highlighted completion text
- Focus transitions within the address bar area — including clicking into the text box, opening its context menu or interacting with the suggestion popup — share a unified focus zone; delayed `GotFocus` events only reset inline completion upon genuine entry from outside with unchanged input revision
- Closing the suggestion popup (dismiss) reliably cancels running background lookups, empties the bound suggestion collection, and closes the native WinUI popup; outside pointer clicks dismiss the popup immediately, and delayed rows can no longer reopen the popup after selection or focus loss
- Suggestion updates incrementally mutate a stable collection rather than rebinding the list on every pass, eliminating redundant rebinds (0 rebinds down from 35) and halving collection modification notices on row shifts
- Tab quick-matches only populate an empty list during background searches, preventing complete history and bookmark results from being prematurely crowded out by partial tab matches

### Nova's own permission dialogs

- Location, clipboard reading and six advanced device permissions (sensors, MIDI, local fonts, window management, file access, multiple automatic downloads) are now asked in Nova's own dialogs instead of the browser engine's. Your answer lands in Nova's permission settings, where you can look it up and change it
- Location offers Allow (saved), Only this time and Block (saved). Escape means "not now", and the details say what the page actually receives — including when a location is being emulated in that tab
- Clipboard reading is answered for the current session, and the dialog says so; copying is never affected
- Each of the six device permissions has its own explanation, and an answer for one never counts for another
- All permission dialogs share one layout: the same button order, the same icons, and no button dressed up as the recommended one
- Resetting a site's permissions also clears the answers given for the current session

### Sign-ins, certificates and downloads that Nova asks about itself

- Websites that ask for a user name and password in the browser (HTTP sign-in, for example a protected folder) get Nova's own dialog. It names the site and the server's description, and warns when the password would travel unencrypted. Such pages used to end on an error page
- The sign-in dialog offers matching logins from the password vault and can save a new one
- An invalid certificate opens Nova's own dialog: it names the host and the problem (expired, issued for another address, broken chain) and says plainly what continuing means. An exception lasts for the session and applies only to the sandbox or tab profile where you made it
- Several certificate errors at once are asked one after the other instead of being refused silently
- Choosing "Back" in the certificate dialog shows a "connection not secure" page instead of an empty dark tab
- The certificate viewer in site info says what is wrong with a certificate that could not be verified
- When a website asks for a client certificate, Nova asks which one to send. Nothing is preselected, and "Send none" is a valid answer
- Before a file that Windows can run is saved, Nova asks. "Discard" is the default, and the warning does not claim to know whether the file is harmful

### Guided setup for AI programs

- A step-by-step setup connects Claude Code, Codex, Antigravity and similar programs to Nova: what was found on this computer, how to connect, which files Nova changes, and how to check the result
- The setup writes nothing while you open it or page through it; every change is a button you press
- Antigravity is detected automatically — syncing across its separate configuration files — and its Nova entry can be kept in sync automatically
- The installer has a preselected checkbox that opens the setup on first start
- Open it any time from **Settings → AI & agents → Set up**, or ask your agent to open it
- Connecting in an empty project automatically seeds `CLAUDE.md`, `AGENTS.md` and `GEMINI.md` guidance files for your AI assistant
- Fixed an issue where the setup wizard wrote configuration changes before reaching the confirmation step naming the affected files, and improved error feedback on failed connections

### Sandboxes

- Up to 100 sandboxes instead of 4. When the add button is disabled, a line underneath says why
- The sandbox bar scrolls with arrows and the mouse wheel instead of pushing the tab bar aside, and a search flyout finds any sandbox by name
- In a narrow window, compact pills show the sandbox letter instead of identical globe icons
- A pill can show which sandbox it is — a colour or the site's icon. Off by default
- Links that a sandbox opens in a new tab or pop-up now stay in that sandbox's session, so you stay signed in. These tabs carry a badge with the sandbox letter, survive a restart and can be switched off per sandbox with a right-click on its pill
- Ctrl+Tab and Ctrl+1…8 follow the tabs you actually see, and on a sandbox the page receives these shortcuts again
- When a page in a sandbox needs a step on another site — an age check, a sign-in, a payment — Nova asks instead of blocking silently. Sites you allow are listed per sandbox in settings and can be removed there
- A link to another program (`mailto:`, `tel:` and similar) inside a sandbox explains why it does not open there
- Renaming, deleting, recovering, clearing data or choosing a proxy for a sandbox now says so when the change did not take effect
- The setup card of a sandbox without a start page no longer shows an empty search pill, and its buttons carry icons

### Password vault

- Logins can be added, edited and copied in settings; editing needs the same identity check as revealing a password
- The account picker comes back when you click into an empty field or press Arrow down, works with the keyboard, follows dark mode, scrolls when the list is long and stays at the field while the page scrolls
- Right-click **Fill saved login** on an input field when a matching login exists
- Sign-ins that ask for the e-mail first (Google, Microsoft, OpenAI) get the password filled on the second step too
- On pages that only ask for the password, the picker sits at the password field instead of the page's search bar, and no nameless entry is created
- Changing a password saves the new password, not the old one
- Filling leaves alone what you already typed and prefers the real user name or e-mail field
- Different ports on the same host (`localhost:3000`, `localhost:8080`) keep separate logins; existing entries without a port keep working
- Subdomains are matched along public suffixes: short brand domains reach their subdomains, while shared hosting such as `vercel.app` or `github.io` no longer shares logins between projects
- Fixed an issue where corrupted vault files caused logins to be deleted; settings now report read failures without touching data
- Filling also works next to `autocomplete=off` password fields, on forms that re-render and with form libraries, saving is also offered after link-style sign-in buttons, and identical logins differing only in letter case are shown once

### Transcription window

- **Settings → Tools → Transcription** adds a toolbar button (off by default) that opens a window: drop or choose a file, watch the transcript appear with timestamps, copy it or save it as TXT, SRT or VTT
- Transcription runs entirely on this computer and reads what Windows can play — MP3, M4A, MP4/MOV, WMA, FLAC, WAV at any sample rate, WebM, and MKV with Opus audio
- Transcribing long recordings calculates progress from measured audio signals even for headerless media, with accurate timing display

## Downloads

- Downloads, die Nova selbst ausführt, nutzen einen Proxy deiner Wahl: den globalen (Standard), den eigenen der Sandbox, keinen oder ein bestimmtes Profil. Der Download-Bereich zeigt, welcher Weg aktiv ist
- Der Download-Bereich zeigt ruhige Zeilen wie Chrome: Symbol, Name, Host und Größe und nur die Aktion, die zum aktuellen Zustand passt
- Ein Fehler wurde behoben, bei dem das Schließen eines Tabs laufende Hintergrund-Downloads aus dem Blick verlor
- Ein Fehler wurde behoben, bei dem das Beenden von Nova ohne Warnung erfolgte, während Downloads aktiv liefen
- Ein Fehler wurde behoben, bei dem zwei gleichzeitige Downloads mit demselben Dateinamen einander überschreiben konnten
- Tempo und Restzeit sind stabil, und ein Download ohne Daten für 15 Sekunden erscheint als „Stockt"
- Ein unterbrochener Download behält „Fortsetzen", und „Erneut versuchen" ersetzt nie die Seite in deinem aktiven Tab
- Mit 401/403 abgelehnte Downloads werden nicht automatisch wiederholt, `blob:`/`data:`-Downloads bieten keine Wiederholung an, und Formular-Absendungen werden nicht als einfache Anfrage erneut geschickt
- Versteckte Richtungszeichen werden aus Dateinamen entfernt, und eine fehlende Endung kommt aus dem Dateityp des Servers
- Der Bereich behält „Mehr laden", aktualisiert offene Details, prüft fehlende Dateien im Hintergrund und fasst gedrosselte Fertig-Meldungen zu einer zusammen
- SFTP- und FTP-Dateitransfers reihen sich nahtlos neben Web-Downloads ein, inklusive Fortschrittsbalken und Pause-/Fortsetzen-Knöpfen
- „Alle fortsetzen“ im Download-Bereich und über MCP (`downloads_resume_all`) nimmt nun auch unterbrochene, aber wiederaufnehmbare Downloads (`Interrupted` mit `CanResume`) wieder auf, statt nur rein pausierte Downloads zu starten
- „Alle leeren“ im Download-Bereich gibt zugrundeliegende WebView2-Download-Handles vollständig frei, sodass abgeschlossene oder abgebrochene Downloads Dateisperren und Speicher umgehend freigeben
- Das Pausieren oder Unterbrechen eines Downloads setzt die Geschwindigkeitsanzeige sofort auf Null zurück, statt veraltete Übertragungsraten einzufrieren

- `nova.eval` und `nova.cdp` melden ein abgelehntes Skript bzw. eine abgelehnte Nutzlast als solche, samt Hinweis, dass ein unveränderter zweiter Versuch nichts bringt

- Zeilenzähler für Chatnachrichten (`assistantTurnCreated`, `outboundMessageAppeared`) melden `null`, solange null Zeilen passen, damit ein unkalibrierter Detektor nicht fälschlich das Ausbleiben einer Nachricht behauptet
