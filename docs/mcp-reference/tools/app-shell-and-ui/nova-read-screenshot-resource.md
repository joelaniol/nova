# `nova.read_screenshot_resource`

> **Reads an in-memory screenshot artifact URI (nova://screenshot/...) and returns base64 image data.**

* **Security Tier:** Tier 1 (Read-Only Visual Extraction)
* **Core Feature Guide:** [Native Dialogs & UI Prompts](../../../core-features/native-dialogs-and-prompts.md)
* **Master Catalog:** [MCP Tool Catalog](../../tool-catalog.md)

---

## 1. Overview

`nova.read_screenshot_resource` resolves custom screenshot URIs generated by visual capture tools, returning PNG base64 strings and dimensions.

## 3. Protocol Usage

### JSON-RPC Request
```json
{
  "name": "nova_read_screenshot_resource",
  "arguments": {
    "uri": "nova://screenshot/snap-9901"
  }
}
```

### JSON-RPC Response
```json
{
  "content": [
    {
      "type": "text",
      "text": "Read screenshot snap-9901 (1920x1080 PNG)."
    }
  ],
  "structuredContent": {
    "ok": true,
    "uri": "nova://screenshot/snap-9901",
    "width": 1920,
    "height": 1080,
    "format": "png",
    "base64": "iVBORw0KGgoAAAANSUhEUgAA..."
  }
}
```
