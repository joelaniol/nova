# `nova.scheduled_task_workspace_list`

Lists files and subdirectories located within a task’s shared workspace folder.

---

## 1. Overview

`nova.scheduled_task_workspace_list` returns file entries stored in a task's `shared/` directory. Output files generated by background runs (JSON reports, CSVs, markdown summaries) can be cataloged and selected for reading.

* **Security Tier:** Tier 1 (Read-Only)
* **Core Architecture Guide:** [Scheduled Tasks & Background Automation Engine](../../../core-features/scheduled-tasks.md)

## 4. Operational Best Practices

* **Shared Directory Confinement:** Path traversal (`../`) outside the task's `shared/` directory is strictly blocked.
* **Fetch Specific Files:** Pass discovered filenames to [`nova.scheduled_task_workspace_read`](nova-scheduled-task-workspace-read.md).
