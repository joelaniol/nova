# `nova.scheduled_task_import`

Imports scheduled task definitions from a JSON array, creating fresh task IDs and isolated workspaces.

---

## 1. Overview

`nova.scheduled_task_import` reads a JSON array (as a string, in `tasksJson`) generated by `nova.scheduled_task_export` and instantiates new scheduled tasks. Each imported task receives a new generated task ID and its own dedicated workspace, preventing ID collisions with existing tasks. A task whose `displayName` already matches an existing task is skipped rather than overwritten; a task with an unrecognized `executorKind`, or a blocked `command` for the `CustomCommand` executor, is also skipped — the rest of the array still imports. Imported tasks are created enabled, the same as a fresh `nova.scheduled_task_create` call.

* **Core Architecture Guide:** [Scheduled Tasks & Background Automation Engine](../../../core-features/scheduled-tasks.md)

## 3. Protocol Examples

### JSON-RPC Request
```json
{
  "name": "nova.scheduled_task_import",
  "arguments": {
    "tasksJson": "[{\"displayName\":\"Price Tracker Imported\",\"prompt\":\"...\",\"cronExpression\":\"daily 09:00\"}]"
  }
}
```

### JSON-RPC Response
```json
{
  "content": [
    {
      "type": "text",
      "text": "Imported 1, skipped 0 of 1 task(s).\n\nImported:\n- 'Price Tracker Imported' (b3c5d7e9f1a2)"
    }
  ],
  "structuredContent": {
    "importedCount": 1,
    "skippedCount": 0,
    "totalCount": 1,
    "imported": [
      "'Price Tracker Imported' (b3c5d7e9f1a2)"
    ],
    "skipped": []
  }
}
```

## 4. Operational Best Practices

* **Re-Arm Secrets:** Because secrets are DPAPI-encrypted per machine and omitted from exports, re-inject any required API keys using [`nova.scheduled_task_secret_set`](nova-scheduled-task-secret-set.md) after importing.
* **Rename Before Re-Importing:** A task is skipped (not overwritten) if its `displayName` already matches an existing task, so rename duplicates in the export before importing them again.
* **Review After Import:** Imported tasks start enabled on their stored schedule, same as newly created ones — review or disable them with [`nova.scheduled_task_disable`](nova-scheduled-task-disable.md) before they fire if that is not wanted.
