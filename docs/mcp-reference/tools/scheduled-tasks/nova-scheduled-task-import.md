# `nova.scheduled_task_import`

Imports scheduled task definitions from a JSON array, creating fresh task IDs and isolated workspaces.

---

## 1. Overview

`nova.scheduled_task_import` reads a JSON array generated by `nova.scheduled_task_export` and instantiates new scheduled tasks. Each imported task receives a fresh UUID and dedicated workspace, preventing ID collisions with existing tasks.

* **Capability Bundle:** `scheduled_tasks`
* **Security Tier:** Tier 2 (Batch Creation)
* **Core Architecture Guide:** [Scheduled Tasks & Background Automation Engine](../../../core-features/scheduled-tasks.md)

---

## 2. Parameter Reference

| Parameter | Type | Required | Default | Description |
| :--- | :--- | :---: | :---: | :--- |
| **`tasksJson`** | `string` | Yes | `none` | JSON array of task definitions produced by `nova.scheduled_task_export`. |
| **`_meta`** | `object` | No | `null` | Optional call metadata. |

---

## 3. Protocol Examples

### JSON-RPC Request
```json
{
  "name": "nova.scheduled_task_import",
  "arguments": {
    "tasksJson": "[{\"displayName\":\"Price Tracker Imported\",\"prompt\":\"...\",\"cronExpression\":\"daily 09:00\"}]"
  }
}
```

### JSON-RPC Response
```json
{
  "content": [
    {
      "type": "text",
      "text": "Imported 1 task successfully (created task-5510f8)."
    }
  ],
  "structuredContent": {
    "ok": true,
    "importedCount": 1,
    "createdTaskIds": [
      "task-5510f8"
    ]
  }
}
```

---

## 4. Operational Best Practices

* **Re-Arm Secrets:** Because secrets are DPAPI-encrypted per machine and omitted from exports, re-inject any required API keys using [`nova.scheduled_task_secret_set`](nova-scheduled-task-secret-set.md) after importing.
* **Review Default State:** Imported tasks default to disabled or paused to allow inspection before automated firing begins.
